AI-powered Revenue Management System

Hotels set room prices by hand from spreadsheets and instinct. I led the architecture of a platform that prices rooms with ML instead, and it now runs across ~70 hotels in Malaysia.

Problem
Pricing has to react to demand, competitors and business rules, for every property, every day.
What I built

Result
A multi-tenant, multi-property SaaS deployed across ~70 hotels, with expansion planned toward 200 properties.

COVA: enterprise agentic AI infrastructure

The generative AI layer behind Aviara Connect. Agents answer questions and act across contracts, purchase orders, invoices, obligations, renewals, partners and documents.

Problem
Business answers live in both structured records and unstructured documents, and each user may only see their own tenant's data.
What I built
Production RAG and agent workflows: semantic and vector retrieval, structured database retrieval, hybrid search, tool calling, specialised agents, conversation context and enterprise memory.
Result
Agents reason across records and documents while staying inside tenant isolation and permission-aware access boundaries.

LLMOpsObservability

Aviara Eye: LLMOps and AI observability

When an agent gives a wrong answer, you need to see why. I set up centralised tracing and prompt management for every production generative AI app.

Problem
Agent failures were black boxes, and prompts were scattered across services.
What I built
A self-hosted Langfuse deployment, instrumenting LLM calls, prompts, tool executions, agent workflows and full execution traces.
Result
Engineering teams debug failures, inspect agent behaviour, manage prompts centrally and monitor production AI from one place.
  • Langfuse
  • LLM tracing
  • Prompt management
  • Agent observability
  • LLM evaluation
  • Docker
